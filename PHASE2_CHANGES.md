# CareerHub Phase 2

## Candidate UX cleanup
- Removed the long candidate navigation list for Profile, Edit Profile, Alerts, Messages, Interviews, Saved Searches, History and Saved Companies.
- Added a compact 🔔 Activity Center in the navbar.
- Activity Center includes quick access to those features plus the latest notifications and unread counts.
- Existing routes/features were preserved; this is a navigation/UX consolidation, not a destructive removal.

## Smart recommendations
- Candidate dashboard recommendations now use a weighted 0–100 match score.
- Signals include preferred role/title relevance, skills, location/work mode, experience and salary preference.
- Each recommendation displays the score and up to four transparent match reasons.

## Run
Use the same one-click flow from Phase 1:
1. First run: double-click `setup.bat`.
2. Later runs: double-click `start.bat`.
